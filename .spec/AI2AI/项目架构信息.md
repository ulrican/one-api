## 1. 项目总览

One-API 二次开发项目：高并发 AI 模型聚合网关。单体 Go 后端（Gin + Gorm + Redis）+ 嵌入式 React 前端（Go `embed` 打包静态资源，单二进制部署）。

- 后端入口：`main.go`；路由：`router/`（`main.go`→`api.go`/`web.go`/`relay.go`/`dashboard.go`）
- 数据面：`relay/`（协议转换与流式透传，修改需极度谨慎，禁止同步 DB 查询）
- 管控面：`controller/` + `model/` + `middleware/`
- 公共层：`common/`（config、redis、i18n、logger、embed-file-system 等）
- 前端：`web/`（多主题，见下）

## 2. 前端架构（web/）

### 2.1 三套主题

| 主题目录 | 技术栈 | 说明 |
| :--- | :--- | :--- |
| `web/default/` | React 18 + CRA5(react-scripts) + Semantic UI + react-router-dom v6 + i18next + recharts | **默认生效主题**（`config.Theme`，env `THEME`，默认 `default`） |
| `web/berry/` | React + Material-UI(Berry 模板) | 可选主题 |
| `web/air/` | React + Semantic UI（旧版） | 可选主题 |

- `web/THEMES` + `web/build.sh`：依次构建三主题至 `web/build/<theme>/`（build.sh 为 bash 脚本，Windows 下需直接在各主题目录执行 `npx react-scripts build`）
- 本地开发：在主题目录执行 `npm start`（react-scripts dev server，默认 3000 端口，`package.json` 内 proxy 指向后端 `http://localhost:3000`，故通常用 `PORT=3007` 等避让）；CRA5 + Node 20 下 ESLint 依赖树不兼容（报 `Environment key "jest/globals" is unknown`），已在 `web/default/.env` 设 `DISABLE_ESLINT_PLUGIN=true`（与 build.sh 约定一致）及 `BROWSER=none`
- 后端 `router/web.go`：`static.Serve` 托管 `web/build/<Theme>`，`NoRoute` 对非 `/api`、`/v1` 路径回退 `index.html`（SPA fallback）

### 2.3 全局布局机制（Task02 阶段 3 后）

`index.js` 中 `AppLayout` 根据路由切换布局：

- **常规页面**（Task3-4 起结构）：`.app-frame`（**flex column, height:100vh; overflow:hidden**）包 `<Header/>`（顶部导航，flex-shrink:0）+ `.app-shell`（**flex:1 1 0; min-height:0; overflow:hidden; flex 行**）：左为 `<SideNav/>`（212px/收缩 64px，全高，`.app-sidenav-scroll` 独立竖向滚动），右为 **`.app-main-col`（Task3-4 新增，flex:1; flex column; overflow:hidden）**，内容列内含 `<Container className="main-content"><App/></Container>`（**flex:1; overflow-y:auto/overflow-x:hidden，内容独立竖向滚动**）+ `<Footer/>`（**flex-shrink:0，钉在内容列底部**）。菜单与内容各自独立竖向滚动、互不干扰。
  - **Footer（Task3-4 改造）**：从 `.app-frame` 底部移入 `.app-main-col`，**只占内容区宽度、不再横跨侧栏**；高度 **32px**（`min-height:32px; display:flex; align-items:center; font-size:12px`，透明底 + 顶部 1px 分隔线）。
  - **侧栏聊天入口（Task3-4 常驻）**：`getChatItem()` 始终返回聊天项（默认/开启 Playground → `/playground`；仅未开 Playground 但配了 `chat_link` → `/chat` iframe），不再因功能开关缺失。
  - **内容间距（Task3-4 收紧）**：页面根容器 `.dashboard-container`/`.chat-shell`/`.topup-page`/`.pricing-page`/`.rankings-page` padding 统一 `12px 16px 16px`（原 20px 24px 40px / 24px 24px 48px）。

- **全屏独立页面**（`STANDALONE_PATHS = ['/', '/login', '/register', '/reset', '/user/reset', '/oauth/github', '/oauth/lark']`）：仅渲染 `<App/>` + `<ToastContainer/>`，不套全局 Header/Container/Footer
  - `/` 为落地页（自带导航页脚）
  - 认证页由 `components/AuthLayout.js` 提供全屏居中玻璃卡布局（登录/注册/重置/重置确认四页复用）

### 2.6 全站双主题机制（Task02 阶段 1 新增）

- **主题 class 挂在 `<html>`**：`theme-dark`（科技暗色，默认）/ `theme-light`（简约亮色）。首帧前由 `public/index.html` 内联脚本设置（防白闪），运行时由 `ThemeContext`（`context/Theme/`）同步。
- **令牌**：`theme/tokens.css` 在 `html.theme-dark` / `html.theme-light` 上定义全套 CSS 变量（品牌色 `--brand-*`、表面 `--bg-page/surface/elevated/inset/glass`、文本四级 `--text-*`、边框 `--border-*`、语义软底色 `--success/warning/danger/info/purple-soft-*`、阴影光晕 `--shadow-*`/`--glow-*`、字体 `--font-sans/mono`）。
- **Semantic UI 覆盖**：`theme/semantic-ui.css` 用 `:where(html.theme-dark, html.theme-light)` 零特异性前缀覆盖 SUI 组件（菜单/卡片/表格/表单/下拉/按钮/标签/消息/Modal/Popup/Dropdown 菜单/Toast/分页/Tab 等）；**Modal/Dropdown 等 Portal 渲染在 body 下，故主题 class 必须挂 html/body 级而非页面容器**。移除 class 即恢复 SUI 原样（回退保障）。
- **主题状态**：`useTheme()` 返回 `{ theme, isDark, isLight, toggleTheme, setTheme }`；持久化 localStorage `app_theme`；初始化优先级 `app_theme` → Task01 旧 `landing_theme`（tech/simple 自动迁移）→ `prefers-color-scheme` → dark。
- **切换组件**：`components/ThemeToggle.js`（胶囊 🌙/☀️），`className` 可传入复用页面样式（Landing 传 `tl-theme-toggle`）。
- **Landing 令牌关系**：`landing.css` 基础令牌继承全局变量；`.tech-landing` 仅保留落地页专属槽位（暗色），亮色由 `html.theme-light .tech-landing` 覆盖；代码终端两主题恒深色。
- **全局框架（Task3-3 更新，`theme/app-frame.css`）**：顶部导航 `.app-header` 为 sticky 玻璃导航（`position:sticky;top:0;z-index:100`，flex-shrink:0），菜单项与首页顶部导航一致——`topNavLinks`（首页/价格/排行榜/关于，`app-nav-active` 蓝色下划线）+ 品牌区 + 右侧 ThemeToggle/语言/用户菜单；**桌面端 Container `maxWidth:'100%'` 占满页宽**（Task3-3，原 1600px 收窄已废弃）。**左侧菜单栏 `components/SideNav.js` 为全高栏**（Task3-3）：`aside.app-sidenav` 贴左边缘，**`height:100%` + flex 拉伸**（Task3-2 的 `position:sticky;top:56px;height:calc(100vh-56px)` 已废弃——独立滚动布局下不再需要 sticky），栏面 `--bg-surface` + 右边框分隔；结构 = `.app-sidenav-scroll`（菜单滚动区，flex:1 + overflow-y:auto，**独立滚动**）+ `.app-sidenav-footer`（收缩按钮）。菜单数据统一在 `components/navConfig.js`：`getChatItem()` 独立聊天入口（playground_enabled→/playground；否则 chat_link→/chat；都无→null）渲染为顶部 `.app-sidenav-chat`——**Task3-3 关键变更：默认态与常规菜单项视觉一致（透明底 + `--text-secondary` + `--brand-blue` 图标），不再恒品牌渐变高亮**，避免被误以为"选中态恒为聊天项"；命中路由时（`.app-sidenav-chat-active`）才切换到品牌渐变 + 白字 + 光晕；`getNavGroups()` 分组：**常规**[总览/令牌/日志]→**资源**[充值/价格/排行榜]→**账户**[设置/关于]→**管理**[渠道/兑换/用户，仅 isAdmin()]（i18n 键 `sidenav.group.*`）。**展开/收缩**：底部 toggle（«/»）切换 `.app-sidenav-collapsed`（212px↔64px，width 0.2s 过渡，状态持久化 localStorage `app_sidenav_collapsed`）；收缩态 label/分组标题隐藏、图标居中、聊天项变 40px 圆角方块、菜单项原生 title 提示。布局：`.app-shell` **flex:1 1 0;
