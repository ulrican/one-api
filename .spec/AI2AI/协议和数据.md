### 1.7 扩展表：`channel_model_sources`（Task4-2 模型库渠道凭证，已实施）

> 模型库渠道（渠道类型 52 七牛 / 53 其他）的独立访问凭证表，一渠道一行；**channels 核心表零改动**，渠道转发凭证仍走 `channels.key`（七牛场景两值同源，保存时自动回填）。`model/channel_model_source.go`，AutoMigrate 注册。

| 列 | 类型 | 说明 |
| :--- | :--- | :--- |
| id | int64 PK | 自增 |
| channel_id | int uniqueIndex/index | 关联 channels.id |
| source_type | varchar(20) index | `qiniu_library` / `other_library`（常量 model.LibrarySourceQiniu/Other） |
| api_base_url | varchar(512) | 可选自定义网关；空 = 七牛官方 |
| api_key | varchar(512)，`json:"-"` | **AES-256-GCM 密文**（兼容字段，可空） |
| api_secret | varchar(512)，`json:"-"` | **AES-256-GCM 密文**（七牛 Bearer Token） |
| last_sync_at | bigint | 上次"刷新模型列表"时间戳（秒） |
| created_at / updated_at | bigint | 时间戳（秒） |

- 加解密：`common/secret.go`（AES-256-GCM，`base64(nonce||ciphertext+tag)`；密钥 `CRYPTO_SECRET` → `SESSION_SECRET` → 开发兜底值；空串原样往返；解密失败报错不静默）。
- `UpsertChannelModelSource`：空串字段跳过不覆盖（与 EpaySecret 留空不改同语义），`ON CONFLICT(channel_id)` upsert；`GetChannelModelSource` 返回解密视图 `ChannelModelSourceView`（**明文仅 AdminAuth 接口下发**）；`TouchChannelModelSourceSync` 只刷时间戳；`DeleteChannelModelSource` 渠道删除时清理。
- 删除联动：`Channel.Delete()`（含 F9 批量删除）best-effort 删本表；`DeleteDisabledChannel`/`DeleteChannelByStatus` 先 Pluck id 再按 `channel_id IN (...)` 清理，加密凭证不残留。
- 渠道类型常量：`relay/channeltype/define.go` 新增 `QiniuLibrary=52`、`OtherLibrary=53`（接在 GeminiOpenAICompatible=51 后、Dummy 前；方案文档曾估算为 57/58，实际代码库 Dummy=54，以实现为准）。**不注册独立 adaptor**：`ToAPIType` 无 case 默认 `apitype.OpenAI` → `openai.Adaptor`（七牛 API 兼容 OpenAI 协议），relay/ 零改动。

### 1.8 扩展表：`model_ratio_locks`（Task4-3 模型倍率手动锁定，已实施）

> 倍率自动重算流程的"跳过名单"，一模型一行；**不改动 option 表既有 ModelRatio/CompletionRatio/GroupRatio 三 key**，锁定行只控制自动流程是否覆盖。`model/model_ratio_lock.go`，AutoMigrate 注册（实测 2026-09-18）。

| 列 | 类型 | 说明 |
| :--- | :--- | :--- |
| model_id | varchar(128) PK | 与 `ratio.ModelRatio` 的 key 一致（七牛 id 含 `/`，如 `deepseek/deepseek-v3.1`） |
| model_ratio | decimal(12,6) | 锁定时的输入倍率快照（0 = 锁时现值也无，允许） |
| completion_ratio | decimal(12,6) | 锁定时的输出倍率快照 |
| locked_by | int（DB 实际 bigint） | 操作人 user_id |
| locked_at | bigint | 锁定时间戳（秒） |
| note | varchar(256) | 备注（可空） |

- `UpsertModelRatioLock`：`ON CONFLICT(model_id)` 全列更新（重复锁定=更新，幂等，locked_by/locked_at 以最新操作者为准）；`DeleteModelRatioLock` 删行解锁（未命中不报错，倍率现值保留，下次重算覆盖）；`GetAllModelRatioLocks`（locked_at DESC）/`GetModelRatioLockMap`（重算热路径用 map）/`IsModelRatioLocked`。
- 写锁定的 Service 入口 `model.LockModelRatio(modelId, *float64, *float64, lockedBy, note)`（`model/ratio_compute.go`）：先 upsert 锁定行（指针项传 nil = 快照现值，仅加锁不改值），再把非 nil 的倍率经 `ratio.Apply*Updates` + `UpdateOption` 立即落 option 表热生效。
