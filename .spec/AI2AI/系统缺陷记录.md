### DEF-003【中】Playground 功能开关可被直接输入 URL 绕过

- **位置**：[web/default/src/App.js#L341-L350](file:///e:/97_OneAI/one-api/web/default/src/App.js#L341-L350)（路由仅 PrivateRoute，无开关判断）；开关只在 [navConfig.js#L10-L17](file:///e:/97_OneAI/one-api/web/default/src/components/navConfig.js#L10-L17) 控制侧栏入口指向

## 4. 已知限制 / 运维注意（非代码缺陷，排障时参考）

1. **ServerAddress 决定支付回调可达性**：[controller/pay.go#L107](file:///e:/97_OneAI/one-api/controller/pay.go#L107) 回调地址取 `config.ServerAddress + /api/user/pay/notify`。当前 dev 环境实测为 `http://localhost:3000`（容器内端口，宿主机映射是 3008），**启用真实支付前必须改成支付平台可公网访问的地址（HTTPS 域名）**，否则平台回调不可达、订单永不入账。
2. **2FA 仅门控密码登录**：OAuth（GitHub/飞书/微信）与 access token 调用不经过 TOTP（F12 设计决策，见 Task2-1-F12 规划）；会话吊销（epoch）同样仅作用于 cookie 会话。
3. **SQLite 存量数据卷重启 FATAL**：容器在已初始化的 SQLite 卷上重启可能触发 AutoMigrate 解析存量 DDL 报 `invalid DDL, unbalanced brackets`（空卷正常），上游迁移缺陷。**规避**：Windows 下不要 bind mount SQLite，持久化直接用 MySQL（当前环境已是 MySQL 8.2 + one-api 库，不受影响）；根因修复待独立后端任务。
4. **首次启动约 3 分钟"假死"**：日志停在 token encoders 初始化（tiktoken 下载/解压 BPE 数据），期间端口不监听、HTTP 全拒，完成后自动 `server started`；缓存落盘后二次启动约 30s。排障时勿误判死锁提前 kill。
5. **渠道变更最长 60s 生效**：渠道缓存按 SYNC_FREQUENCY 定时同步、无事件失效；新建/启停渠道后进 relay 路由最长延迟 60s（渠道测试接口直读 DB 不受此限）。
6. **路由剔除参数为 env 启动固化**：`ROUTING_EXCLUDE_THRESHOLD`/`ROUTING_EXCLUDE_WINDOW_SECONDS` 在 routingstats 包初始化时读取，修改需重启进程（不像 option 可运行时生效）。
