## F15 排行榜

### 设计决策
- **option 开关 `RankingEnabled`（默认 false）**：公开排行榜暴露运营数据，部署方可能希望低调运营。关闭时 API 返回 `success=false, message="disabled"`，前端 EmptyState 提示。
- **厂商推断**：controller 层硬编码前缀正则推断（gpt-*→OpenAI 等），不写 DB，未匹配归 "Other"。一次查询同时返回模型+厂商两维度。
- **时间范围**：today/week/month/year（默认 today），ISO 周一起始。
- **缓存**：Redis 60s（key `rankings:{range}`），无 Redis 降级直查 DB。
- **Header 入口**：与 Pricing 同款无条件渲染（让 API 返回 disabled 时前端 EmptyState 处理），避免依赖 status 加载时序。

## F18 第三方客户端集成菜单

### 设计决策
- **纯前端**：数据源只是 `window.location.origin+'/v1'`（公开）和用户自己的 token key。
- **硬编码客户端列表**：`constants/clients.js`，三种行为：link（网页拼参跳转）/ copy（展示 base_url+key 可复制）/ deeplink（本地唤起+下载 fallback）。
- **入口**：Playground 工具栏"接入客户端"按钮 + TokensTable 行内"接入"图标按钮，共用同一 Modal。
- **无 option 开关**：不暴露运营数据，用户登录后即可用。

## 验证方案

### F15 后端 API E2E
- PUT /api/option/ RankingEnabled=true → GET /api/rankings?range=today/week/month/year → 对照 `SELECT model_name,count(1) FROM logs WHERE type=2 AND created_at BETWEEN ? GROUP BY model_name` 逐项一致
- 厂商聚合：providers 中 OpenAI 项 = SQL 中所有 gpt-*/o1-* 前缀之和
- Redis 缓存命中：`GET rankings:today` 有值，二次请求响应时间显著降低
- 关闭开关：GET /api/rankings 返回 success=false, message="disabled"

### F15 前端浏览器走查
- Header 出现"排行榜"入口；/rankings 加载展示 hero+range Tab+dimension Tab+表格
- 切换 today/week/month/year 数据更新；切换 model/provider 无新请求
- 暗色/亮色无穿帮；关闭开关后 EmptyState 提示

### F18 前端浏览器走查
- Playground 工具栏"接入客户端"按钮 → Modal token 下拉自动选中当前 token
- base_url 显示 `origin/v1`，key 显示 `sk-xxx`
- LobeChat 卡片"打开"→ 新窗口拼参正确；Chatbox 卡片→ 两栏可复制；OpenCat→ deeplink+下载 fallback
- TokensTable 行内"接入"图标 → Modal 预填该行 token
